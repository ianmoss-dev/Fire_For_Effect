# FIRE for Effect Web

Mobile-first React frontend for the rebuild.

Run locally:

```powershell
npm install
npm run dev
```

Build and lint:

```powershell
npm run build
npm run lint
```

Set `VITE_API_BASE_URL` to point at the FastAPI backend. If it is not set, the app uses `http://127.0.0.1:8000`.
