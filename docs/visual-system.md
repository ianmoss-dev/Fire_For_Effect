# FIRE for Effect Visual System

FIRE for Effect should feel related to Napkin Math, but more technical and planning-focused.

## Shared Family Tokens

Fonts:

- Interface: `DM Sans`
- Major headings and large numbers: `Playfair Display`

Colors:

- Navy: `#1B3A6B`
- Blue: `#2E75B6`
- Gold: `#C9A84C`
- Light blue: `#D5E8F0`
- Light gold: `#FEF9EE`
- Gray: `#595959`
- Light gray: `#F2F2F2`
- White: `#FFFFFF`
- App background: `#F8F9FA`
- Green: `#2E7D32`
- Light green: `#E8F5E9`
- Red: `#C62828`
- Light red: `#FFEBEE`

## Layout Direction

- Build mobile first around a 390px to 430px viewport.
- Use a centered max-width shell for phone-sized flows.
- Let desktop add comparison space and chart width, not a separate product concept.
- Use one primary action per screen.
- Keep sections compact and scannable.
- Prefer summary-first views with expandable detail.

## FIRE-Specific Tone

Use plain, useful language.

Good:

- `Monthly take-home`
- `Required savings rate`
- `Projected pension`
- `Chance of reaching target`
- `Cash left after expenses`

Avoid:

- Motivational filler
- Long paragraphs inside controls
- Jokes in financial outputs
- Dense legalistic explanations before the user sees their numbers

## Chart Rules

- Every chart needs a one-line takeaway metric above it.
- Mobile charts should start with the answer, then reveal detail.
- Use labels that work without a legend when possible.
- Avoid Sankey as the only mobile cash-flow view.
- Preserve advanced charts for desktop or expanded detail.

## Component Direction

- Cards should be individual result blocks or repeated items, not nested layouts.
- Inputs should be grouped by the decision the user is making.
- Use segmented controls for modes.
- Use toggles for binary settings.
- Use sliders only when approximate input is acceptable.
- Use exact numeric inputs for pay, debt, rates, and retirement targets.

## Relationship to Napkin Math

Napkin Math is the simple intake and budgeting app.

FIRE for Effect is the deeper military planning app.

They should share:

- Typeface
- Core palette
- Mobile rhythm
- Direct wording
- Calculation-first product feel

They should differ in:

- Density of financial outputs
- Use of dashboards and comparisons
- More advanced charts
- Stronger support for long-form planning
